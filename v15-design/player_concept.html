NEOTJAPLAYER ・ 再設計の全体像（案）

作った譜面を、
見せる・残す・確かめる

Editor が「作る」道具なら、新しい Player は作った譜面を人に届け、自分で確かめるための再生機。遊ぶためのシミュは TNDE・Anasoko・Handler・1D2S・Nauts にまかせて、作譜者と鑑賞会の主催者にしか要らない機能に絞る。

設計の決まりは1つだけ。再生・描画・録画は Editor と同じ部品（PreviewDock・game_screen・recorder）を使い、作り直さない。直せば両方に効き、TNDE と同じ時刻の読み方もそのまま手に入る。

機能マップ

いまの Player にある（流用） あるものを広げる 新しく作る P2着手する段階

見せる（鑑賞会）

主催者が置いておけば、会が勝手に進む

  • プレイリスト（メドレー）並べた順に流す。並べ替え・飛ばす・シャッフル。がばさんの案P1
  • 曲間のインターバル秒数を決めて、次の曲まで待つP2
  • 曲紹介カードTITLE・MAKER・難易度・★を数秒出してから流すP2
  • 全画面と主催者用の操作次へ・戻る・一時停止をキー1つで。マウスの矢印は隠すP2
  • 曲ごとの音量そろえ音圧の違う曲が続いても、聞こえ方をそろえるP2
  • 難易度選択画面本家の座標を再現したもの。単発で開くときに使うP1

残す（映像制作）

撮り直しなしで、編集ソフトに渡せる形にする

  • まとめ録画並べた譜面を1本ずつ書き出す。失敗しても次へ進むP1
  • プレイリストを1本の動画に曲紹介カードと間も入れて、メドレー動画にするP3
  • チャプター書き出しYouTube の概要欄に貼れる「0:00 曲名」の一覧を同時に出すP3
  • 背景の透過・クロマキーレーンだけを書き出して、編集ソフトで重ねるP3
  • 出力の形の選び直し4K・60fps・レーンだけ・縦長などを1つの欄で選ぶP3

確かめる（作譜に役立つ）

叩いてみた結果を、譜面の直しに返す

  • 簡易プレイいまの演奏モード。判定はすべて鬼の値P4
  • 小節ごとのミスの地図不可・ミスが多い小節を色で出す。押すと Editor でその小節を開くP4
  • 区間練習2点の間を繰り返す。速さも変えられるP4
  • 早い・遅いの分布押しにくい配置や、ずれやすいリズムを見つけるP4
  • 直す前と後を並べて流す同時再生の応用。2つの版の違いを目で比べるP4

土台（3本とも使う）

曲一覧 player/library.py 再生と4つのモード preview_dock.py 録画 recorder.py 判定の記録 player/play_state.py 設定は Editor と共有 プレイリストのファイル形式 新しい窓の骨組み

進め方

P0片付け

次のアプデで、いまの Player を外す

  • Editor の「Player を起動」と「Player を落としますか？」の案内を外す
  • リリースに Player の exe が無くても、Editor の更新が通ることを実際に試す
  • 告知:「手元の旧 Player は使えるが、更新は止まる。作り直し中」

出来上がり: Editor だけのリリース

P1土台

新しい窓と、プレイリスト

  • 画面の案を1枚見せてから作る
  • 曲一覧から選んでプレイリストに足す。並べ替え・保存・読み込み
  • いまの曲一覧・難易度選択・まとめ録画を新しい窓に載せ替える

出来上がり: 並べて、1曲ずつ流せる・録れる

P2最初に出す

鑑賞会がほったらかしで回る

  • 順番に流す・インターバル・曲紹介カード
  • 全画面と、主催者用のキー操作
  • 曲ごとの音量そろえ

出来上がり: 新 Player の最初のリリース。ここで募集の声をもう一度聞く

P3映像

メドレー動画を1回で書き出す

  • プレイリストを1本の動画に。チャプター一覧も一緒に出す
  • 透過・クロマキー、出力の形の選び直し
P4確かめる

叩いた結果を譜面の直しに返す

  • 小節ごとのミスの地図から、Editor の該当小節へ飛ぶ
  • 区間練習、早い・遅いの分布、直す前と後の比較
P5募集

集まった要望を、3本の柱のどこかに入れる

  • どの柱にも入らない要望は「遊ぶためのシミュ」寄りなので、入れるかを相談する

先に決めること

  1. P2 と P3 のどちらを先に出すか鑑賞会が近いなら P2、動画の需要が強いなら P3
  2. プレイリストのファイルEditor で作る .json と同じ考え方で、人に渡せる形にするか
  3. 曲紹介カードに出す項目TITLE・MAKER・難易度・★のほかに要るもの（応募番号など）
  4. オートで流すときの打音鳴らす・鳴らさない・音量

気をつけること

  • Player を外す版の更新旧 Player を持っている人の更新が止まらないか、出す前に試す
  • 再生の部品は Editor と共有Player のために変えた所は Editor にも効く。両方で確かめる
  • 音量そろえは曲を先に読む読み込みに時間がかかるので、裏で済ませて流すまでに間に合わせる
  • 素材はこれまでどおり System からTNDE などの素材は同梱しない
