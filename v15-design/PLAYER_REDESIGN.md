# NeoTJAPlayer 再設計 — 構想と進め方（レビュー用）

作成: 2026-11-16 / 対象: NeoTJAEditor v15.3.0 時点のコード
状態: **案**。まだ実装していない。P0（旧 Player の削除）だけは次のアプデで先に出したい。

## 1. 背景

- NeoTJAEditor には、Editor とは別の exe「NeoTJAPlayer」（再生・録画専用）が付いている。
- 作者は Player を作り直すことにした。理由は、遊ぶためのシミュレーター（TNDE、Anasoko、Handler、1D2S、Nauts など）はすでにたくさんあり、同じものを作っても意味がないから。
- 作り直すのは「**作譜に役立つ**」Player。Discord で欲しい機能を募集中で、最初に来た案は「指定した順番に、間隔を置いて譜面を流す（メドレー）。鑑賞会をほったらかしで回せる」。
- 旧 Player は、新しいものと混同されるので**消す**。

## 2. 構想

> Editor が「作る」道具なら、新しい Player は **作った譜面を見せる・残す・確かめる** ための再生機。

対象は、作譜者と鑑賞会の主催者。プレイ用シミュにある機能（スキン、段位、オンライン等）は追わない。

### 設計の決まり（外すと作り直しになる）

1. **再生・描画・録画は Editor と同じ部品を使う。** `PreviewDock` は `MainWindow` を参照しておらず、結合はコールバックだけ（必須は `apply_offset_cb`）。Player は `PreviewDock` を1つ作って、その再生ウィンドウを見せるだけで、4つのモード・速度・コース切替・録画・TNDE と同じ時刻の読み方がそのまま手に入る。
2. **録画は画面外の専用ウィジェットを1コマずつ描く方式**（`recorder.make_offline_widget`）。画面を撮らないので、書き出し中に他の操作をしても影響しない。
3. **判定（演奏）の状態は再生とは別の入れ物に閉じ込める**（`player/play_state.py`）。再生の画面は「いまの時刻」から全部を導く状態なしの作りで、シークや録画のコマ飛ばしに強い。判定を混ぜるとそれが壊れる。
4. **素材は利用者の System フォルダから読む。** TNDE などの素材は同梱しない（再配布不可）。
5. **設定は Editor と共有**。保存は読み直して自分のキーだけ書き戻す。

## 6. P0: 旧 Player の削除（次のアプデ）

### 何を消すか

1. **リリースに `NeoTJAPlayer.exe` を載せない。** `NeoTJAPlayer.spec` はビルドしない（ファイルは新 Player で使うので残す）。
2. **Editor から旧 Player への入口を外す。** `main_window.py` の「実行」メニュー:
   - 「NeoTJAPlayer を別ウィンドウで開く」（`launch_player`、~3465）
   - 「NeoTJAPlayer を入れ直す」と、落とすか尋ねる処理（~3507〜3575）
3. **利用者の PC にある旧 Player を消す。** 新しい Editor の初回起動時に、Editor の exe と同じフォルダにある `NeoTJAPlayer.exe` を **ごみ箱へ移す**（完全削除にしない。間違いでも戻せるように）。
   - 更新の bat は**更新前の（古い）Editor が作る**ので、bat では消せない。新しい Editor が起動してから消す。
   - 旧 Player が起動中で掴まれているときは、消さずに次の起動でもう一度試す（何度も聞かない）。
   - 消すのは Editor の隣にあるものだけ。別の場所に置いたもの・ショートカットは触らない（ショートカットはリンク切れになる。告知で伝える）。
   - **毎回の起動で**確かめる（設定に「消した」印は付けない）。旧版へ戻して Player が復活したあと、また新版へ上げたときにも消せるようにするため。
   - 消すのは、exe のバージョン情報が **15.3.x 以下**と読めたものだけ。読めない・15.4 以上なら残す（将来の新 Player を消さない）。
   - ごみ箱への移動が失敗したら成功扱いにしない。Editor の起動は止めない。
4. **バージョン変更（旧版へ戻す機能）との整合。**
   - `updater.UpdateDownloadWorker` は `require_player=version_change` のとき、リリースに Player が無いと失敗する（`updater.py` ~343）。v15.4.0 以降を選んだときに失敗しないよう、「その版に Player があるか」で決める。
   - 旧版（Player 付き）へ戻したときは、旧版の Editor が自分で Player を落とすので、そのまま。
5. **紛らわしい名前の整理。** 内蔵のゲーム画面も「NeoTJAPlayer」と呼んでいる（`main_window.py` ~2038「F1: NeoTJAPlayer(内蔵プレビュー)」など）。旧 Player と混同されるので「ゲーム画面」に言い換える。ネームプレートの既定の称号「NeoTJAPlayer」は今回は触らない（要相談）。

### 消さないもの

- `neotja/player/` のコード（新 Player が library・batch・select_screen・play_state を使う）
- 設定の Player 用のキー（害がない。新 Player で使うかもしれない）
- GitHub の過去のリリースに載っている旧 Player（旧版へ戻す機能が使う）

### 更新の流れで確かめること

- v15.3.0（Player 付き）の Editor から、Player の無いリリースへ更新できるか。
  - `UpdateCheckWorker` は Player の URL が無ければ空文字を渡し、通常の更新では Player を落とさない（`updater.py` ~219〜224、~371）。読んだ限りは通るが、**出す前に実際に試す**。
- 更新後の初回起動で旧 Player がごみ箱へ移るか。起動中の旧 Player がある場合に落ちないか。

## 7. 先に決めること

1. P2（鑑賞会）と P3（映像）のどちらを先に出すか
2. プレイリストのファイル形式（ネームプレートの .json と同じく、人に渡せる形にするか）
3. 曲紹介カードに出す項目（応募番号などが要るか）
4. オートで流すときの打音（鳴らす・鳴らさない・音量）
5. 新 Player も別 exe にするか、Editor の中のモードにするか（作者は「独立させている」前提）

## 8. 気をつけること

- 再生の部品は Editor と共有。Player のために変えた所は Editor にも効くので、両方で確かめる。
- 音量そろえは曲を先に読む必要がある。裏で済ませて、流すまでに間に合わせる。
- 鑑賞会は数時間流しっぱなしになる。メモリが増え続けないか（曲ごとに画面や音声を作り直す・捨てる）。
- テストでは利用者の本物の `settings.json` を触らない（`settings_path` などを一時ファイルへ向ける）。

## 9. レビューしてほしい点

1. 3本柱（見せる・残す・確かめる）の切り方は妥当か。抜けている「作譜に役立つ」機能はあるか。
2. 段階の順番（P1→P2 で最初に出す）は妥当か。P2 に入れる量は多すぎないか。
3. P0 の旧 Player の消し方（新 Editor の初回起動で、隣の exe をごみ箱へ）に穴はないか。特に:
   - 更新の bat・バージョン変更機能との組み合わせ
   - 旧 Player が起動中・別の場所にある・読み取り専用の場所にある場合
4. 「再生は PreviewDock を使い回す」前提で、プレイリスト連続再生（数時間）を作るときの落とし穴（音声デバイス、メモリ、ffmpeg の後始末など）。
5. プレイリスト1本を1つの動画にする録画（P3）は、`batch.py` を広げるのと、`recorder` に連結の仕組みを足すのと、どちらが筋がいいか。

## 11. 連続再生の状態遷移（P1 で決める・たたき台）

```
待機 ──開始──▶ 読み込み中 ──完了──▶ 紹介カード ──秒数──▶ 再生中 ──終了位置──▶ 余韻 ──▶ インターバル ──▶ 次の曲の 読み込み中
                  │                                                                      │
                  └─失敗─▶ 飛ばす（記録して次へ）                                         └─最後の曲─▶ 終了画面
```

決めること:

- **終了位置**: 「音声の終わり」ではなく「譜面の最後の小節の終わり + 余韻」。音源より長い譜面・短い譜面の両方で同じ規則にする（録画の長さと同じ考え方）。
- **読み込み待ち**: 紹介カードを出している間に次の曲を読み込む。間に合わなければカードを延ばす。
- **失敗**: 音源が無い・解析できない曲は飛ばし、一覧に印を付けて最後にまとめて見せる（まとめ録画と同じ）。
- **最後の曲のあと**: 終了画面で止まる（繰り返しは設定で選ぶ）。
- **「次へ」の連打**: 読み込みのたびに番号（世代）を振り、古い読み込みの完了通知は捨てる。
