# プレイリスト仕様 (2026-11-19 決定)

## 置き場所
- 左の一覧: NeoTJAEditor の「保存済み楽曲」の下に「プレイリスト」。
- 押すと作成済みプレイリストの一覧。各プレイリストはタイトル・説明・ジャケット(未設定なら1曲目のジャケット)。
- プレイリストを開くと、いつものジャンルを開いたときと同じ曲一覧。試聴(1回目クリック)もできる。

## 編集
- プレイリスト選択中に「曲を追加」ボタン → 追加モードで曲をクリックして追加。曲の右クリック「プレイリストに追加」も。
- 追加時に難易度も決めて保存。
- 並べ替え: ドラッグ。外す: 右クリック。同じ曲の重複は可。
- TJA が見つからない曲は灰色にして飛ばす。
- 保存先: 設定とは別ファイル (任せる → playlists.json 予定)。

## 再生
- 単独再生: 一覧の曲から通常どおり。
- 連続再生: 範囲指定 (どこからどこまで、既定は1〜最後) + 手動 / 自動 を選ぶ。
- 手動: 毎曲、プレイ画面直前のタイトル画面で止まる。タイトル画面は今の表示を左に寄せ、右に「再生する」ボタン・何曲目/何曲・難易度変更。結果画面は出さない。
- 自動(完全オート): タイトル画面で約10秒待って自動で進む(秒数は設定可)。結果画面は出さない。前提: すべてオート再生。
- 途中 Esc メニューに「次の曲へ」を追加。「やめる」でプレイリストごと終了。
- 最後まで行ったらプレイリストの画面に戻る。

## exe の横のフォルダ (2026-11-19 要望、できたら)
- NeoTJAEditor.exe の横に専用フォルダを作り、そこへ保存する: 録画の出力 / YouTube から取った動画 / プレイリストの json / ジャケット画像。
- 目的: 間違えて消す事故を防ぐ。既存のファイルは移さない。これから保存する分だけ新フォルダへ。

## 録画
- プレイリスト全体を1本にまとめた録画 + 曲ごとの個別録画。(最後に作る)
